「Webコンテンツ作成」の成果

本テーマについて

本テーマでは、HTML・CSSによるページ構造と装飾の基礎から、JavaScriptによるDOM操作・イベント処理・Ajax通信までを学び、それらを組み合わせて動的でインタラクティブなWebページを自ら設計・実装できるようになることを目標とする。

プロジェクト課題について

プロジェクト課題では「世界の天気」と題したWebページを作成した。カイロ・モスクワ・ヨハネスブルク・北京・東京・シンガポール・シドニー・ロンドン・パリ・リオデジャネイロ・ニューヨーク・ロサンゼルスの12都市からドロップダウンで都市を選択し、「検索」ボタンをクリックすると、axiosライブラリを用いた非同期のAjax通信でOpen Weatherの天気情報を取得し、緯度・経度・天気・最低気温・最高気温・湿度・風速・風向・都市名をリスト形式で表示するとともに、天気アイコンもあわせて表示する。HTMLでページ構造を、CSSでレイアウトと配色を実装し、JavaScriptでは検索結果を表示する前に前回の表示内容を削除する処理を入れることで、何度検索しても結果が累積しないようにした。

プロジェクト課題で作成したページ:project.html

数当てゲーム

数当てゲームは、コンピュータが Math.random() を用いてランダムに決めた1から10までの整数を、プレイヤーが3回以内に当てるゲームである。プレイヤーはテキストボックスに予想する数値を入力し、「回答」ボタンをクリックするか、入力欄でEnterキーを押すことで判定が行われる。ボタンのクリックイベントとキー入力イベントの両方に addEventListener でハンドラを登録しており、どちらの操作からでも同じ判定処理 hantei() が呼び出される仕組みになっている。判定処理では、入力値と正解を比較し、「もっと大きいですよ」「もっと小さいですよ」といったヒントをDOM操作でページ上に表示する。正解した場合や3回とも外れてゲームオーバーになった場合には、その旨と正解の数値を表示し、ゲーム終了後にボタンを押しても再挑戦できないよう制御している。

数当てゲームのページ: kazuate.html

各授業回の学習事項

第1回 WWW と HTML

今回はHTMLの基本構造と要素について学習した。HTML文書はdoctype宣言・html・head・body要素で構成され、headには文字コードやタイトルを、bodyには表示内容を記述する。要素にはブロック要素とインライン要素があり、インライン要素の中にブロック要素を入れることはできない。 また、タグのミスはFirefoxのソース表示などでデバッグできる。

演習の成果: 演習1-4: HTMLのさまざまな要素

第2回 CSS による Web ページの装飾

今回はCSSを使ったWebページの装飾方法について学習した。CSSをHTMLに適用する方法には、外部スタイルシート・内部スタイルシート・インラインスタイルの3通りがある。CSSの書式はセレクタ・プロパティ名・プロパティ値の3つで構成される。セレクタで装飾対象の要素を指定し、プロパティ名と値で装飾の内容を記述する。font-sizeやbackground-colorなど様々なプロパティがあり、paddingのように上下左右をまとめて一括指定できるものもある。

演習の成果: 演習2-3: ブラウザと CSS の基本

第3回 JavaScript の基本

第3回では、プログラミング言語 JavaScript の基本的な文法について学習した。HTML に JavaScript を組み込むには <script> タグを使い，defer 属性を付けることでページの読み込みが完了した後にスクリプトを実行できる。JavaScript では let キーワードで変数を宣言し，文字列・数値・真偽値などのデータ型を扱える。また，console.log() 関数を使ってブラウザの開発者ツールのコンソールに値を出力することでデバッグが行える。さらに、オブジェクトと配列という2つの重要なデータ構造を学んだ。オブジェクトは {} で定義し，プロパティをキーと値のペアで格納する。プロパティへのアクセスはドット記法（オブジェクト名.プロパティ名）で行う。配列は [] で定義し，複数の値を順序付きで管理する。for-of 構文を用いることで，配列の各要素や，オブジェクトの配列に対して繰り返し処理を簡潔に記述できる。

演習の成果: 演習3-6: オブジェクトのメンバーを出力する

第4回 DOM と JavaScript

第4回では、DOM（Document Object Model）を通じて JavaScript からHTMLを動的に操作する方法を学習した。ブラウザはHTML文書をツリー構造のDOMとして保持しており、document.querySelector() でセレクタに一致する要素を取得できる。取得した要素の textContent や innerHTML プロパティを書き換えることでページの内容を動的に変更できる。また、document.createElement() と appendChild() を組み合わせることで新しい要素をページに追加でき、element.style プロパティを利用すればCSSのスタイルもJavaScriptから直接変更できる。これらの操作により、ユーザの操作に応じてページを再読み込みせず動的に更新するインタラクティブなWebページを作成できる。

演習の成果: 演習4-10: 足し算ページ

第5回 イベント処理

第5回では、ユーザの操作に応じて処理を実行するイベント処理の仕組みと、DOM操作の応用について学習した。要素にイベントハンドラを登録するには addEventListener() を用い、第1引数にイベントの種類（"click" など）、第2引数に実行する関数を指定する。ハンドラの引数として受け取れる event オブジェクトの event.target プロパティを参照すると、実際にイベントが発生した要素を特定できるため、同じ処理を複数の要素にまとめて登録する場合に便利である。また、classList.add() や classList.remove() を使うと要素に付与するクラスを動的に切り替えられ、CSSと組み合わせてクリックした要素の見た目を変化させることができる。DOM操作については、insertAdjacentElement() で既存の要素の前後や内部に新しい要素を挿入する方法、setAttribute() で要素の属性（画像の src やリンクの href など）を書き換える方法、remove() で要素をページから削除する方法をあわせて学んだ。

演習の成果: 演習5-7: DOM の演習その2

工夫点，苦心点，強調点，感想

本演習を通じて特に工夫した点は、プロジェクト課題における検索結果表示の設計である。単に取得したデータをそのまま表示するのではなく、緯度・経度・天気・気温・湿度・風速・風向・都市名といった複数の項目を見やすいリスト形式でまとめ、あわせて天気アイコンの画像も表示することで、一目で状況が把握できるページを目指した。また、検索ボタンを押すたびに前回の検索結果が画面に残ってしまうと結果が累積して見づらくなるという問題があったため、printDom() 関数の冒頭で表示領域の中身を毎回クリアしてから新しい結果を描画するようにし、何度検索しても常に最新の結果だけが表示されるように工夫した。

苦心した点は、Ajax通信の非同期処理の流れを正しく理解し実装することであった。ボタンをクリックしてから axios.get() でリクエストを送信し、レスポンスが返ってくるまでの間はブラウザが他の処理を続けられるという非同期の考え方は、これまで学んできた同期的なプログラムの書き方とは異なり、最初はどの関数がいつ呼び出されるのか整理するのに時間がかかった。.then() を用いて成功時の処理、.catch() で失敗時の処理、最後の .then() で通信完了後に必ず実行される処理を分けて記述するという axios の書き方に慣れるまで、練習問題のサンプルコードを何度も読み返しながら理解を深めた。

強調したい点は、検索対象を当初の5都市から、参考資料に示されていた12都市すべてに拡張したことである。都市IDだけで検索できる仕様であったため、指定されたすべての都市IDをドロップダウンに反映することで、検索機能としての網羅性と使いやすさを高めることを意識した。また、HTML・CSS・JavaScriptをそれぞれの役割に応じて分離して記述し、構造・装飾・振る舞いを明確に分けて実装することで、コード全体の見通しをよくすることにも注意を払った。

全体を通しての感想としては、HTMLとCSSで静的なページを作ることから始まり、JavaScriptとDOM操作でページに動きを持たせ、最終的にはAjax通信によって外部のサーバから実際のデータを取得して表示するところまで、段階的に技術を積み重ねて学べたことが非常に有意義であった。特にプロジェクト課題では、これまでの回で学んだ内容をすべて組み合わせる必要があり、個々の技術がどのようにつながって一つのWebページを作り上げているのかを実感することができた。今後Webコンテンツを作成する機会があれば、今回学んだ非同期通信の考え方やDOM操作の技術を積極的に活用していきたい。
