プロジェクト課題について

プロジェクト課題では「世界の天気」と題したWebページを作成した。北京・東京・シドニー・ロンドン・ニューヨークの5都市から都市をドロップダウンで選択し、「検索」ボタンをクリックすると、その都市の緯度・経度・天気・最低気温・最高気温・湿度・風速・風向・都市名がリスト形式で表示され、天気アイコンも合わせて表示される。HTMLでページ構造を記述し、CSSで青系のカラースキームとフレックスボックスによるレイアウトを実装した。JavaScriptでは都市ごとの天気データをオブジェクトとして管理し、ボタンのクリックイベントを検知してDOMを操作することでページを動的に更新する仕組みを実装した。

プロジェクト課題で作成したページ:project.html

数当てゲーム

数当てゲームは、コンピュータがランダムに決めた1から10の整数を3回以内に当てるゲームである。プレイヤーがテキストボックスに数値を入力して「回答」ボタンを押すと、JavaScriptが正誤を判定し、「もっと大きい」「もっと小さい」「正解」などのメッセージをDOMを操作してページ上に表示する。乱数の生成には Math.random() を用い、ボタンのクリックイベントには addEventListener でハンドラを登録した。3回すべて外れるとゲームオーバーとなり正解が表示される。

数当てゲームのページ: kazuate.html

各授業回の学習事項

第1回 WWW と HTML

今回はHTMLの基本構造と要素について学習した。HTML文書はdoctype宣言・html・head・body要素で構成され、headには文字コードやタイトルを、bodyには表示内容を記述する。要素にはブロック要素とインライン要素があり、インライン要素の中にブロック要素を入れることはできない。 また、タグのミスはFirefoxのソース表示などでデバッグできる。

演習の成果: 演習1-4: HTMLのさまざまな要素

第2回 CSS による Web ページの装飾

今回はCSSを使ったWebページの装飾方法について学習した。CSSをHTMLに適用する方法には、外部スタイルシート・内部スタイルシート・インラインスタイルの3通りがある。CSSの書式はセレクタ・プロパティ名・プロパティ値の3つで構成される。セレクタで装飾対象の要素を指定し、プロパティ名と値で装飾の内容を記述する。font-sizeやbackground-colorなど様々なプロパティがあり、paddingのように上下左右をまとめて一括指定できるものもある。

演習の成果: 演習2-3: ブラウザと CSS の基本

第3回 JavaScript の基本

第3回では、プログラミング言語 JavaScript の基本的な文法について学習した。HTML に JavaScript を組み込むには <script> タグを使い，defer 属性を付けることでページの読み込みが完了した後にスクリプトを実行できる。JavaScript では let キーワードで変数を宣言し，文字列・数値・真偽値などのデータ型を扱える。また，console.log() 関数を使ってブラウザの開発者ツールのコンソールに値を出力することでデバッグが行える。さらに、オブジェクトと配列という2つの重要なデータ構造を学んだ。オブジェクトは {} で定義し，プロパティをキーと値のペアで格納する。プロパティへのアクセスはドット記法（オブジェクト名.プロパティ名）で行う。配列は [] で定義し，複数の値を順序付きで管理する。for-of 構文を用いることで，配列の各要素や，オブジェクトの配列に対して繰り返し処理を簡潔に記述できる。

演習の成果: 演習3-6: オブジェクトのメンバーを出力する

第4回 DOM と JavaScript

第4回では、DOM（Document Object Model）を通じて JavaScript からHTMLを動的に操作する方法を学習した。ブラウザはHTML文書をツリー構造のDOMとして保持しており、document.querySelector() でセレクタに一致する要素を取得できる。取得した要素の textContent や innerHTML プロパティを書き換えることでページの内容を動的に変更できる。また、document.createElement() と appendChild() を組み合わせることで新しい要素をページに追加でき、element.style プロパティを利用すればCSSのスタイルもJavaScriptから直接変更できる。これらの操作により、ユーザの操作に応じてページを再読み込みせず動的に更新するインタラクティブなWebページを作成できる。

演習の成果: 演習4-10: 足し算ページ

第5回 イベント処理

第5回では、ユーザの操作に応じて処理を実行するイベント処理の仕組みと、DOM操作の応用について学習した。要素にイベントハンドラを登録するには addEventListener() を用い、第1引数にイベントの種類（"click" など）、第2引数に実行する関数を指定する。ハンドラの引数として受け取れる event オブジェクトの event.target プロパティを参照すると、実際にイベントが発生した要素を特定できるため、同じ処理を複数の要素にまとめて登録する場合に便利である。また、classList.add() や classList.remove() を使うと要素に付与するクラスを動的に切り替えられ、CSSと組み合わせてクリックした要素の見た目を変化させることができる。DOM操作については、insertAdjacentElement() で既存の要素の前後や内部に新しい要素を挿入する方法、setAttribute() で要素の属性（画像の src やリンクの href など）を書き換える方法、remove() で要素をページから削除する方法をあわせて学んだ。

演習の成果: 演習5-7: DOM の演習その2
